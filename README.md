# 🎫 Concert Ticket Booking System

A purely Java-based application developed in Eclipse IDE to streamline concert ticket reservations, seat selection, and event management.

---

## 🚀 Key Features
* **User Authentication:** Secure registration and login workflows.
* **Concert Catalog:** Browse upcoming concerts and check ticket availability.
* **Seat Selection & Booking:** Select seats, reserve tickets, and calculate total pricing.
* **Booking Confirmation:** Generate booking details and summaries for users.
* **Admin Management:** Manage concert listings and view system records.

---

## 🛠️ Tech Stack
* **Language:** Java
* **IDE:** Eclipse IDE
* **Version Control:** Git & GitHub

---

## 💻 How to Run
1. Download or clone this repository to your computer.
2. Open **Eclipse IDE**.
3. Go to **File > Open Projects from File System...** and select the project folder.
4. Locate your main executable class (containing `module-info`), right-click, and select **Run As > Java Application**.
